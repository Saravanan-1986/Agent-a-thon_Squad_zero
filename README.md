# Knowledge Debt Engine

## Tagline

Find the gap. Diagnose the cause. Fix it. Prove it.

## Problem

Students can carry unresolved conceptual weaknesses into later
learning. A single incorrect answer does not necessarily mean a
persistent conceptual gap. The system therefore needs to track evidence
over time, identify persistent weaknesses, intervene, and verify whether
the weakness has actually been repaired.

## Solution

Knowledge Debt Engine maintains a persistent record of unresolved
learning gaps and manages their lifecycle:

Detect → Diagnose → Intervene → Verify → Adapt → Re-verify

## Core Principle

LLM proposes. Evidence decides.

## Main Components

- Evidence Agent
- Diagnosis Agent
- Intervention Agent
- Verification Agent
- Orchestrator
- Mentor Review
- Knowledge Debt Ledger
- Prerequisite Graph
